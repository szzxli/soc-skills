A small JSON file containing this profile plus a SHA-256 hash of its contents. 03 · AI GRADING

AI grading BETA

Self-assessment is a claim. Grading is the check. Paste your evidence, bring your own API key — the rubric grades it, right here in your browser. Your key never leaves this device except to the API provider you choose.

1 · Your API key (free signup · free models — grading costs $0)

Get a free key at openrouter.ai/keys (no credit card). The default model is free — any model ending in :free costs $0 on OpenRouter. Paid models work too if you set a spend limit. Stored only in this browser's localStorage. Sent directly to your chosen provider — never to our servers (there are none). OpenAI's own API blocks browser calls (CORS); OpenRouter allows them. 2 · Your evidence

Paste a project README, an evidence bundle, or a plain description of what you built and ran. Be specific: file names, what you ran by hand, test counts. The grader only credits observable evidence.
