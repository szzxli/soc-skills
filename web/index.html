FOR SOC JOB SEEKERS & CAREER CHANGERS · FREE · OPEN SOURCE

Turn your labs into an evidence-backed skill profile hiring managers can read.

No SOC job on your resume yet? Show what you can do instead. soc-skills grades your lab write-ups and code against a public rubric — 8 SOC skill domains mapped to the NIST NICE framework, with levels you can only earn with evidence.

  • Know where you stand: a level per domain (L1 → L2), each one tied to the file or report that earned it — ready to walk through in an interview.
  • Know what to build next: a gap analysis spells out what's missing for the next level, domain by domain.
  • Show it, don't claim it: a resume one-liner plus a tamper-evident profile file an employer can check. Runs in your browser — no soc‑skills account needed.

Verification package NEW

A small JSON file containing this profile plus a SHA-256 hash of its contents. Share it with an employer: on the Verify page they can recompute the hash and confirm the profile has not been altered, and see which rubric version it was produced against. 03 · AI GRADING

AI grading BETA

Self-assessment is a claim. Grading is the check. Paste your evidence, bring your own API key — the rubric grades it, right here in your browser. Your key never leaves this device except to the API provider you choose.

1 · Your API key (free signup · free models — grading costs $0)

Get a free key at openrouter.ai/keys (no credit card). The default model is free — any model ending in :free costs $0 on OpenRouter. Paid models work too if you set a spend limit. Stored only in this browser's localStorage. Sent directly to your chosen provider — never to our servers (there are none). OpenAI's own API blocks browser calls (CORS); OpenRouter allows them.
