Verify a profile package

A soc-skills verification package bundles one grading result with a SHA-256 hash of its contents. Paste or upload a package below — this page recomputes the hash in your browser and checks the contents have not been altered since the package was generated. Nothing is uploaded anywhere.

Package JSON

What this verification does and does not prove
  • It proves the profile contents match the SHA-256 hash inside the package — the record has not been altered since the package was generated — and it shows the rubric version the result claims to be graded against.
  • It does not prove the identity of the person assessed, that the underlying evidence was genuine, or that the package was created at the stated time (the timestamp is self-asserted inside the payload). Anyone can generate a package with the public algorithm; a matching hash shows internal consistency, not origin.
  • It is not a proctored exam or a certification. soc-skills grading is advisory and evidence-based; verify the evidence itself in an interview or work sample.
